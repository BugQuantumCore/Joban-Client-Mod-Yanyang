数据快照

每帧一次、由宿主封送的只读数据。全部访问器都是普通内存读取——零 JNI、零反射、零装箱。

快照机制

每帧开始时，宿主把该实例的数据一次性封送成一块 POD 快照（定长头部 + 变长数组池 + UTF-8 字符串池），连同状态块指针一起传给 mtrRender。SDK 的类型化包装器（mtr::Vehicle、mtr::Pids、mtr::Lift、mtr::EyeCandy）在这块内存上提供与 JS Wrapper 同名的访问器：

  • 字符串以 mtr::StrView（data + len）返回，用 .str() 转 std::string、.empty() 判空；视图只在本次 render 调用内有效。
  • 越界索引抛 std::out_of_range（与 Java 端 IndexOutOfBounds 语义一致）。
  • 快照指针与包装器不要跨帧保存。
覆盖范围

快照覆盖高频读取的字段。不在快照里的数据（网络、文件、渲染管理器的深接口等）经 mtr::Api 访问——那是低频通道，别在热路径用。

Vehicle（车辆）

术语：MTR 3 的 train → MTR 4 的 vehicle

MTR 4 统一以 vehicle 称呼载具（资源包声明键 vehicleScripts、Java 侧 VehicleWrapper），本 SDK 的数据包装类因此命名为 mtr::Vehicle。更早版本的 SDK 曾按 MTR 3 习惯命名为 mtr::Train，该名称现保留为源码兼容别名——两种写法均可编译，行为完全一致。

注意：mtr::Vehicle 命名已进入仓库 SDK 源码，将随下一版本的 zip 发布；若你的工程使用 yanyang.7 及更早的 SDK zip，请以 mtr::Train 引用该类（新 SDK 中两种写法均可编译）。

交通模式与类型

两条互补的口径，与 JS 侧 getTransportMode() / getTransportType() 返回完全相同的值，跨语言脚本可共享布局逻辑：

  • 模式（mtr::TransportMode 枚举）：UNKNOWN / TRAIN / BOAT / CABLE_CAR / AIRPLANE，覆盖四种基础载具。
  • 类型（字符串 id，mtr::transport_type 常量）：基础模式的小写名（"train"、"boat"、"cable_car"、"airplane"），加上 MAGIC MTR Addon 的扩展线路类型 train_normal / train_light_rail / train_high_speed / train_metro / train_bus / train_tram / train_sbahn；无法解析时为 "unknown" 或空视图（旧服务器数据）。
if (vehicle.getTransportType() == mtr::transport_type::TRAIN_METRO) { /* ... */ }

for (int i = 0; i < stop.interchange_count(); i++) {
    mtr::Stop::Interchange ic = stop.interchange(i);
    if (ic.getTransportType() == mtr::transport_type::TRAIN_HIGH_SPEED) { /* ... */ }
}
数据来源

MAGIC 类型在客户端装了该 addon 时从本地配置解析；服务器装了而客户端没装时经同步数据集下发；旧服务器不下发线路元数据时返回空 / UNKNOWN——装了本模组的服务器可提供远程车站的完整元数据。

访问器说明

game_time_millis() / in_game_time()时钟

事件详情（玩家、手持物品等）经 Api 读取：

mtr::Api api(ctx.input());
auto event = api.context().call("events").get("onBlockUse");
if (event.call("occurred").as<bool>()) {
    auto detail = event.call("detail");
    auto player = detail.call("player");
    auto item   = detail.call("item");
}

装饰的绘制上下文 EyeCandyContext 提供 draw_model(model, matrices)、play_sound(sound, volume, pitch)、set_outline_shape(boxes, count)、set_collision_shape(boxes, count)（每箱 6 个 float；碰撞箱沿用 Java 端 1.5 格高度上限，超出由宿主校验并记日志）。电梯复用同一上下文类型（LiftContext = EyeCandyContext）。

工具类型

<mtr/util.hpp> 提供热路径友好的轮播工具（零分配）：

// "A|B|C" 每 40 tick 轮换一段，视图切换只做偏移计算
mtr::CycleTracker dest{"KOWLOON|TSUEN WAN"};
StrView current = dest.value(vehicle.in_game_time());
成员说明
CycleTracker(packed, interval_ticks=40)构造轮播（镜像 TextUtil.cycleString）
value(game_tick) / value_str(game_tick)当前活跃段（视图 / 字符串）
interval() / part_count()轮换间隔与段数
StrView{data, len} 字符串视图：.str()、.empty()，可 == 比较
