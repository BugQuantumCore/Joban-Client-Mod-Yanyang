JS → C++ 迁移

把既有 JS 脚本移植成 C++ 原生脚本。两条管线共享几乎一一对应的包装器语义——移植主体是改名与重塑，不是重写。

为什么迁移

先读两页

迁移前先看脚本模型与生命周期（create / render / dispose + 逐实例 State 在两侧完全同构）与JS 脚本入门——本页只讲两侧差异。

  • 一次封送代替数百次反射：JS 侧每读一个字段都是一次跨语言调用；C++ 侧整块快照是平铺 POD，脚本按普通内存读取。
  • 零 GC 压力：没有包装器对象与装箱字符串；绘制记录在内存区里 bump 分配。
  • 崩溃防护：出错的模块自动禁用（native script faulted: module disabled），绝不弄崩游戏。
  • 新能力原生优先：模型着色 / 发光 / 半透明、信号扩展点、道口 / 售检票机 / 广播三类方块脚本（ABI 16）。
  • 何时留在 JS：一次性小脚本、没有编译工具链、需要飞快迭代——选型对照见概览。

生命周期与注册

三个生命周期函数换成虚函数 override；跨帧状态从闭包变量搬进 State 结构体。注册宏随脚本类型选择，资源包声明与 JS 条目同一管线。

JavaScriptC++说明
function create(ctx, state, pids)void create(PidsContext& ctx, State& state, const Pids& pids) override首次渲染前执行一次
function render(ctx, state, pids)void render(...) override每帧执行（尽力而为节律与 JS 相同）
function dispose(ctx, state, pids)void dispose(...) override实例退场清理
跨帧存活的闭包变量State 结构体成员宿主分配、placement-new；基类模板参数换成你的 State 类型
SCRIPT_INPUT JSONapi.input()mtr::Api（ABI 8+），同一份资源包声明输入

注册：MTR_REGISTER_PIDS_SCRIPT(MyScript)——车辆 / 电梯 / 装饰 / 屏蔽门 / 道口 / 售检票机 / 广播分别用 MTR_REGISTER_VEHICLE_SCRIPT / _LIFT_ / _EYECANDY_ / _PSD_ / _LEVEL_CROSSING_ / _FARE_MACHINE_ / _ANNOUNCEMENT_。每个模块一个脚本 id，照旧在 mtr_custom_resources.json 里声明（scriptLocations 分类规则不变）。

半自动转换器

SDK 自带 tools/js2cpp.py（纯标准库、零依赖），把上表的机械部分自动化：

python3 native/tools/js2cpp.py input.js -o output.cpp --id mypack:pids --kind pids

它执行本页全部改名规则、forEach → 索引循环、TextWrapper 链 → mtr::Text 链、属性访问 → getter、模块级变量搬进 State 字段（类型推断 + state. 前缀改写）、Math / console 基础改写；不确定处绝不静默改写，全部留 TODO 标记。

产出预期：一份直接可编译的骨架 + 少量 TODO。随后照编译一节构建，用热重载在游戏里迭代。

端到端示例

同一个「首行到站」PIDS 脚本的两种写法：

let PREFIX = "";                 // 模块级常量

function create(ctx, state, pids) {
    state.ticks = 0;             // 逐实例状态
}

function render(ctx, state, pids) {
    state.ticks++;
    const next = pids.arrivals().get(0);
    const dest = next ? next.destination : "无列车";

    new Text(PREFIX + dest)
        .pos(0, 0).size(pids.width, 14)
        .centerAlign().draw(ctx);
}
#include <mtr/script.hpp>

struct FirstArrivalState { int ticks = 0; };   // 逐实例状态

struct FirstArrival : mtr::PidsScript<FirstArrivalState> {
    static constexpr auto ID = "example:first-arrival";

    void render(mtr::PidsContext& ctx, FirstArrivalState& state,
                const mtr::Pids& pids) override {
        state.ticks++;

        const auto arrivals = pids.arrivals();
        mtr::StrView dest = arrivals.size() > 0
            ? arrivals.at(0).destination() : mtr::StrView{"无列车"};

        mtr::Text::create()
            .text(dest.str().c_str())
            .pos(0, 0).size(pids.width(), 14)
            .center_align().draw(ctx);
    }
};

MTR_REGISTER_PIDS_SCRIPT(FirstArrival)
  • 逻辑逐行对得上：get(0) 的空值检查换成 size() > 0 判空（JS 的 get 越界返回 null，C++ 的 at 越界抛异常——语义差异见数据快照）。
  • Timing.now() 类时钟全部换成快照访问器；闭包变量 state.ticks 原样保留在 State 里。
  • 资源包声明侧：迁移期可让 JS 版与 C++ 版以各自独立的 id 并存于同一资源包（scriptLocations 支持混合声明），逐屏核对输出一致后，再把条目切到 C++ 一侧——声明格式见打包。
