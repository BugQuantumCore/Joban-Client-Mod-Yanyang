JS → C++ 之遷

遷既有 JS 之腳為 C++ 原生之腳。二管線共享幾一一相應之包裝器語意——遷移者，改名重塑而已，非重寫也。

何為而遷

先讀二篇

遷移之前，先觀腳本體例與生命週期（create / render / dispose 與逐實例 State，兩側全同）暨JS 之腳入門——本頁惟述兩側之異。

  • 一舉封送，代數百反思之呼：JS 側每讀一欄，皆跨語言之呼也；C++ 側整塊快照為平鋪 POD，腳本如常記憶體而讀之。
  • 無 GC 之壓：無包裝器之物、無裝箱之字串；繪製之錄，於記憶體區內 bump 而配。
  • 崩潰之防：模塊有過，自禁之（native script faulted: module disabled），遊戲終不崩。
  • 新能先至原生：模型染色 / 發光 / 半透、號誌擴展之點、道口 / 售檢票機 / 廣播三方塊之腳（ABI 16）。
  • 何時留 JS：一次性之小腳、無編譯之具、欲疾其迭代——選型之對照，見綜覽。

生命週期與註冊

生命週期之函數凡三，易為虛函數之 override；跨幀之狀態，自閉包之變數搬入 State 結構。註冊宏隨腳本之類而擇；資源包之宣告，與 JS 條同一管線。

JavaScriptC++釋義
function create(ctx, state, pids)void create(PidsContext& ctx, State& state, const Pids& pids) override首繪之前，一行
function render(ctx, state, pids)void render(...) override每幀一呼（盡力而為之節，與 JS 同）
function dispose(ctx, state, pids)void dispose(...) override實例退場，清理之
跨幀猶存之閉包變數State 結構之成員宿主所配、placement-new；基類模板之參，易為爾之 State 型
SCRIPT_INPUT JSONapi.input()mtr::Api（ABI 8+），同一資源包所宣之輸入

註冊曰 MTR_REGISTER_PIDS_SCRIPT(MyScript)——車輛 / 電梯 / 裝飾 / 屏蔽門 / 道口 / 售檢票機 / 廣播，分別用 MTR_REGISTER_VEHICLE_SCRIPT / _LIFT_ / _EYECANDY_ / _PSD_ / _LEVEL_CROSSING_ / _FARE_MACHINE_ / _ANNOUNCEMENT_。每模塊一腳本 id，照舊宣於 mtr_custom_resources.json（scriptLocations 分類之規不變）。

半自動轉換器

SDK 自攜 tools/js2cpp.py（純標準庫、零依賴），代上表機械之勞：

python3 native/tools/js2cpp.py input.js -o output.cpp --id mypack:pids --kind pids

本頁諸改名之規、forEach → 索引之環、TextWrapper 鏈 → mtr::Text 鏈、屬性之取 → getter、模塊級變數搬入 State 之欄（型之推斷＋state. 前綴之改）、Math / console 基礎之易，皆其司也；不確定者絕不默改，悉留 TODO 之誌。

所出之期：一份徑可編譯之骨架＋少數 TODO。既成，依編譯一篇而構，以熱重載於遊戲之中迭代之。

首尾貫通之例

同一「首行到站」PIDS 腳本，二種書法：

let PREFIX = "";                 // 模塊級之常數

function create(ctx, state, pids) {
    state.ticks = 0;             // 逐實例之狀態
}

function render(ctx, state, pids) {
    state.ticks++;
    const next = pids.arrivals().get(0);
    const dest = next ? next.destination : "無列車";

    new Text(PREFIX + dest)
        .pos(0, 0).size(pids.width, 14)
        .centerAlign().draw(ctx);
}
#include <mtr/script.hpp>

struct FirstArrivalState { int ticks = 0; };   // 逐實例之狀態

struct FirstArrival : mtr::PidsScript<FirstArrivalState> {
    static constexpr auto ID = "example:first-arrival";

    void render(mtr::PidsContext& ctx, FirstArrivalState& state,
                const mtr::Pids& pids) override {
        state.ticks++;

        const auto arrivals = pids.arrivals();
        mtr::StrView dest = arrivals.size() > 0
            ? arrivals.at(0).destination() : mtr::StrView{"無列車"};

        mtr::Text::create()
            .text(dest.str().c_str())
            .pos(0, 0).size(pids.width(), 14)
            .center_align().draw(ctx);
    }
};

MTR_REGISTER_PIDS_SCRIPT(FirstArrival)
  • 邏輯逐行相應：get(0) 空值之察，易為 size() > 0 之判（JS 之 get 越界返 null，C++ 之 at 越界擲——其義之異，見數據快照）。
  • Timing.now() 屬之時鐘，悉易為快照之訪問器；閉包之變數 state.ticks，原樣留乎 State。
  • 資源包宣告之側：遷移之期，JS 本與 C++ 本得以各自獨立之 id 並存於同一資源包（scriptLocations 受混合之宣告）；逐屏核其輸出既同，乃以條目移乎 C++ 一側——宣告之式，見打包。
